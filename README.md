# Conference FX

Локальная обработка своей камеры и своего микрофона перед видеозвонком. Кадры и голос никуда не отправляются.

Программа забирает физическую камеру и микрофон, рисует белые зрачки и поднимает голос, затем отдаёт картинку в виртуальную камеру `Conference FX Camera`. Звук играет в выбранное устройство: наушники для проверки или вход виртуального кабеля, который созвон видит как микрофон.

Детектор лица — UltraFace RFB-320 (около 1 МБ). Зрачок ищется как тёмное пятно внутри глаза, поэтому отдельная тяжёлая сетка лица не нужна и кадр укладывается в 30 fps.

## Сборка

Нужны Visual Studio 2022/2026 с C++ и Windows 10 SDK, 64-битная конфигурация.

```bat
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
```

В Visual Studio откройте `build\conference-fx.slnx`. Стартовый проект — `conference-fx`: F5 собирает его и запускает окно. Рядом с exe уже лежат модель и `onnxruntime.dll`.

Проверки:

```bat
build\Release\pitch_test.exe
build\Release\pupil_test.exe
build\Release\face_test.exe
build\Release\vcam_smoke.exe
```

Окно программы: `build\Release\conference-fx.exe`.

## Устройства в созвоне и в голосовых

1. Запустите Conference FX и нажмите «Зарегистрировать Conference FX Camera». Регистрация пишется в профиль текущего пользователя.
2. В Zoom, Discord, Teams или браузере выберите камеру **Conference FX Camera**.
3. Для голоса поставьте [VB-CABLE](https://vb-audio.com/Cable/) с сайта автора и перезагрузите компьютер. Это donationware: пакет можно копировать только как есть, встраивать его в чужой установщик нельзя, поэтому программа открывает официальную страницу, а не ставит драйвер сама.
4. После перезагрузки программа сама пишет обработанный голос в **CABLE Input**. В Телеграме (голосовое и звонок), Скайпе и Teams микрофоном выберите **CABLE Output**. Свой физический микрофон в этих приложениях выбирать не нужно.
5. Галка «Слушать в наушниках» оставляет копию у вас, если в Windows есть активные динамики или наушники.

Пресеты: «Мультфильм» (тон +5 полутонов, форманты вверх, белые зрачки), «Только зрачки», «Выключено». Если лица в кадре нет, кадр проходит без закраски.

Дополнительный сдвиг звука выравнивает губы и голос. Отрицательное значение выпускает звук раньше.
